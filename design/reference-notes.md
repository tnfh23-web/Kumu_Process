# 원본과 현재 구현

- 사용자 제공 전체 PNG는 1920×23,132px, 12개 섹션이다. PDF보다 길어 이후 Design Output·Closing까지 포함한 PNG를 전체 범위 기준으로 삼는다.
- PC 단일 배치를 유지하며 최소 폭 1280px, 같은 1920px 캔버스의 비율로 표시한다. 모바일·태블릿 재배치는 추가하지 않는다.
- 웹 텍스트는 로컬 Pretendard Variable이며 사용자 지정 예외로 왼쪽 서체 샘플의 서체명·Aa·normal은 PC에 설치된 여기어때 잘난체2 원본을 사용한다. 잘난체 Aa의 대문자 높이와 기준선을 오른쪽 프리텐다드 Aa에 맞춰 크기와 위치를 보정했다. 원본 OTF를 변경 없이 포함하고 저작권·라이선스 전문을 함께 보관한다. 이미지·로고 속 원본 글자는 유지한다. 기존 로컬 Figma 자산을 사용한다. 브라우저 탭에는 사용자가 제공한 강아지 로고를 표시한다.
- 파이는 native SVG로 중심 (140,140)과 반지름 140을 통일했다. 막대는 원본 최종 길이·색을 유지하는 CSS와 native 카운트다. 가상의 설문 결과 표시는 유지한다.
- 2026-11-06 사용자 요청으로 Lenis smoothWheel:true·lerp:.08을 적용했다. 런타임의 GSAP ScrollSmoother는 제거했다. 동작과 cleanup은 motion-plan.md를 따른다.
- 목업·사진의 30개 컨테이너는 RGB 원본과 정적 마스크를 미리 합친 WebP 24개를 사용한다. 적용 사진과 클로징의 큰 사진 5장은 치수와 투명 마스크를 그대로 두고 화면용 WebP로 압축했다. 메인 화면 목업은 무손실 WebP로 제공한다. 단색/둥근 SVG 배경 11곳은 CSS다. 원본 이미지와 SVG는 보관한다.
- 전후 1280×15,421 정적 캡처에서 배치·텍스트는 유지했다. 섹션별 평균 RGB 픽셀 차이는 0~1.24/255이며, 이미지 리샘플링·alpha 처리·둥근 모서리의 안티앨리어싱에서 발생한다. 이미지가 검게 보이거나 필수 크롭이 빠지는 현상이 없는지 실제 화면을 확인한다.
- source/QA·다운로드 중간 산출물은 로컬 work/, qa/에 보관하며 저장소에는 올리지 않는다. 제품 화면과 README는 프로젝트 소개만 유지한다.

- 2026-11-08 메인 화면 이미지의 정적인 polygon 잘림을 동일 해상도 lossless RGBA WebP에 미리 반영했다. CSS 위치·크기·폰 목업 배치는 유지하며 해당 섹션의 전후 정적 캡처 픽셀 차이는 0이었다. 사용자 최종 요청으로 모든 휠 입력은 기본 Lenis .08을 사용하고 별도 native 전환·반전 보정을 제거했다. 등장 트리거·시간·차트 수치는 바꾸지 않았다.

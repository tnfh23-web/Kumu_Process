## 사용자 지시로 유지하는 차이

웹 본문·제목·타이포 샘플은 Pretendard를 사용한다. 원본의 Noto Sans KR/Inter/잘난체 등과 글자 형태와 폭이 다를 수 있다. 로고와 삽입 화면 안의 글자는 이미지 원본이다. 타이포 샘플의 원본 서체명 문구는 내용 보존을 위해 유지했다.

문제 정의의 그라데이션·둥근 하단, 차트 성장, 화면 설명 연결선 등은 CSS/GSAP으로 구현했다. 우측 아래 TOP 버튼과 키보드 건너뛰기 링크는 긴 웹 문서 탐색을 위해 추가했다. 모바일·태블릿 레이아웃 재배치는 요청 범위에 없다.

정적 QA는 1935 × 1080 브라우저에서 15px 스크롤바를 제외한 캔버스 1920 × 23,132px로 수행한다. 긴 원본 높이를 viewport 높이로 사용하지 않는다. `?capture=1`을 사용하며 실제 등장·입력 검수는 일반 주소에서 별도로 수행한다.

## 구성 단위 모션 수정

벡터 조각별 애니메이션을 제거했다. 102개 완성된 구성의 순차 페이드인을 명시하며, 원그래프만 같은 중심·반지름의 네이티브 SVG 부채꼴로 0→82%를 채운다. 변경 전 정적 캡처와 비교했을 때 파이 이외의 11개 섹션과 나머지 배치는 동일하다. README는 소개와 웹 링크만 남긴다.

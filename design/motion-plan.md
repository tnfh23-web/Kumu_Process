# 구성 단위의 순차 페이드인

사용자 수정 요청에 따라 벡터 조각별 등장, 마스크로 가운데가 채워지는 연출, 회전·이동·hover 회전을 제거했다. 로고·툴 아이콘·팔레트·설명은 완성된 구성 전체의 opacity만 바꾼다. 기존 SVG의 정적인 투명도/크롭 마스크는 원본 표시용으로 유지한다.

참고: https://r00neyj.github.io/Eatgo_Process/ 의 자료/본문 순차 등장과 12시 방향에서 진행하는 파이 차트. 레퍼런스의 원형 마스크 스크롤 구현을 그대로 복사하지 않고, 쿠무에서는 실제 82% 부채꼴을 1.45초 동안 그린다. 스크롤을 멈춰도 끝까지 완성된다.

## 표시 단위와 순서

`index.html`에 102개 `data-entry` 구성과 명시적인 `data-entry-batch`, `data-entry-order`를 기록한다. 화면 좌표로 벡터와 글자를 자동 분류하지 않는다. 각 구성의 고정 anchor가 실제 스크롤 진입을 결정한다. 같은 묶음은 0.16초 간격(첫 화면은 0.11초), 각 fade는 0.65초로 겹친다.

| 구간 | 표시 순서와 단위 |
|---|---|

| Overview | label → 제목 → 설명 |
| Research | label → 제목 → 설명 → 좌우 질문 → 파이 → 오른쪽 막대 행 1~4 |
| Problem / Goal | 제목 → 완성된 카드 1·2·3 → 연결 표시 → 목표 제목·본문 |
| Strategy | 제목 → 각 원의 배경·숫자·본문을 함께 1·2·3 |
| Naming / Logo | 제목과 설명 → PRIMARY LOGO의 라벨·도형·글자를 함께 → LOGOTYPE·BRANDMARK·SUBMARK 순서 |

| GUI | 제목 → 기기 이미지 전체 → grid 설명 전체 |

| Closing | 목업·워드마크·문구를 완성된 장면으로 함께 |

## 파이 차트

이미지로 된 서로 다른 크기의 파이 조각을 제거했다. 280 × 280px SVG의 배경 원과 갈색 부채꼴은 모두 중심 (140, 140), 반지름 140을 사용한다. 12시부터 시계 방향으로 0 → 82%를 그리며, 바깥 윤곽은 변하지 않는다. 시각 숫자도 82%로 완성한다. 접근성 설명은 항상 최종 82%를 제공한다.

## 스크롤과 실패 대안

GSAP/ScrollTrigger/ScrollSmoother 3.13.0을 유지한다. smoother는 단일 인스턴스이며 smooth 1.05, smoothTouch .1이다. OS 모션 설정만으로 요청된 모션을 끄지 않는다. 초점·앵커 이동은 해당 구성을 즉시 완성한다. 초기화 실패 또는 준비 시간 초과 시 구성 전체와 82% 차트를 보여주고 네이티브 스크롤을 제공한다.

검수에서는 완료 화면 외에 파이 채움 중간 상태, Tool/로고 하위 조각의 transform·opacity가 개별 변경되지 않는지, 팔레트 배경·테두리·코드가 같은 구성인지 확인한다. 정적 비교는 기존 캡처와 같은 1920 × 23,132px로 실시한다.

각 묶음은 포함된 이미지와 정적인 투명도 마스크의 준비를 기다린 뒤 페이드인을 시작한다. 첫 화면의 장식도 사진과 함께 나타나며 크레딧이 본문보다 먼저 뜨지 않는다.
